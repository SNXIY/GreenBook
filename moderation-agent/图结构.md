# 审核 Agent 图结构（40 个节点）

## 阶段一：预处理

```
START
  │
  ▼
preprocess                     # Unicode 标准化、算 hash
  │
  ▼
select_evidence_strategy       # 决定证据收集策略
 #基础能力具备（开关开 + 模型有 + 能读上下文）→ dynamic，否则 fixed 保底。
  │
  ├─ dynamic → scan_signals
  └─ fixed   → gather_context → scan_signals    # 先查社区上下文再扫描
```

## 阶段二：风险分类 + 证据收集

```
scan_signals                   # 正则+关键词扫描敏感内容
  │
  ▼
classify_risk                  # LLM 评估风险等级
  │
  ▼
route_risk                     # 根据风险等级分流
  │
  ├─ fast    → prepare_low_risk_fast_path → retrieve_evidence
  ├─ fixed   → retrieve_evidence                         # 固定规则收集
  └─ dynamic → initialize_tool_agent                     # LLM 自主调工具
                 │
                 ▼
           moderation_tool_agent ←──── moderation_tools   # LLM ⇄ 工具循环
                 │                       (execute tool)
                 ├─ finalize → evidence_collection_finalize
                 ├─ budget   → mark_tool_budget → evidence_collection_finalize
                 └─ fallback → prepare_fixed_fallback → gather_context (回退)
```

## 阶段三：策略 RAG

```
evidence_collection_finalize
  │
  ├─ review          → select_policy_rag_strategy
  ├─ reviewer_policy → prepare_policy_after_evidence → grader/planner/judgment
  └─ fallback        → prepare_fixed_fallback (回退重来)

select_policy_rag_strategy
  │
  ├─ agentic → policy_query_planner → policy_retriever → policy_grader
  │                         ↑                              │
  │                         └── policy_query_rewriter ←────┤ (rewrite)
  │                                                        │
  │                              accept ─────────────────→ policy_evidence_finalize
  │                              partial_stop → mark_policy_partial_stop → policy_evidence_finalize
  │                              human_stop   → mark_policy_human_stop   → policy_evidence_finalize
  │
  └─ legacy → select_review_mode (跳过 RAG)
```

## 阶段四：判决

```
policy_evidence_finalize
  │
  ├─ review   → select_review_mode
  └─ revision → prepare_judgment_revision (重判)

select_review_mode
  │
  ├─ judge              # 单 LLM 判决
  └─ risk_investigator ──┐
     safe_advocate ──────┤
                         ▼
                adversarial_judge   # 红蓝对抗裁决
                         │
                  ┌──────┘
                  ▼
            check_evidence
```

## 阶段五：证据审查 + 最终路由

```
check_evidence
  │
  ▼
evidence_reviewer              # 审查证据是否充分
  │
  ▼
validate_reviewer_route         # 决定下一步
  │
  ├─ finalize → action_route
  ├─ collect_more_evidence → prepare_tool_revision → moderation_tool_agent (回去再查)
  ├─ retrieve_more_policy  → prepare_policy_revision → policy_rewriter/planner
  ├─ revise_judgment       → prepare_judgment_revision (回去重判)
  └─ human_review          → human_review

action_route
  │
  ├─ auto_pass    → save_final_result
  ├─ auto_reject  → save_final_result
  ├─ auto_limit   → save_final_result
  └─ human_review → save_final_result
                      │
                     END
```

## 关键循环回路

- `moderation_tool_agent ⇄ moderation_tools` — 工具不够继续调
- `policy_grader → policy_query_rewriter → policy_retriever` — 检索不够好重写 query
- `evidence_reviewer → prepare_tool_revision → moderation_tool_agent` — 证据不够回去再查
- `evidence_reviewer → prepare_judgment_revision → judge` — 判断不够回去重判
